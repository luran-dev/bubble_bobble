# Bubble Bobble · Neon Caverns

PC 브라우저에서 실행하는 Bubble Bobble 팬 리메이크입니다. 녹빛 동굴, 입체적인 버블 드래곤, 반투명 버블, 이펙트를 Canvas로 새로 그렸습니다.

## 실행

**`index.html`을 Chrome, Edge 또는 Safari로 열면 됩니다.** 설치, 빌드, 인터넷 연결이 필요 없습니다. 같은 폴더에 `style.css`, `game.js`, `music.js`, `stages.js`를 함께 두세요.

서버로 실행하려면 Python 3.9 이상이 설치된 macOS/Linux에서 다음 스크립트를 사용하세요.

```sh
./server.sh start 8080    # 백그라운드 실행
./server.sh status 8080   # 실행 상태 확인
./server.sh stop 8080     # 종료
```

`./server.sh start --port 8080` 또는 `-p 8080` 형식도 지원합니다. 포트를 생략하면 **4173**입니다. 포트별로 독립적으로 관리하므로 시작할 때 지정한 포트를 종료·조회에도 사용하세요. 다른 작업 폴더에서 스크립트의 절대 경로로 실행해도 됩니다.

- 바인딩 주소: **0.0.0.0** (모든 IPv4 인터페이스)
- 이 PC에서: `http://localhost:8080`
- 같은 네트워크의 다른 기기에서: `http://이-PC의-LAN-IP:8080` (예: `http://192.168.0.10:8080`)
- 외부 기기는 `0.0.0.0` 대신 서버 PC의 실제 IP로 접속하세요. 연결되지 않으면 해당 포트의 OS 방화벽 허용 여부와 같은 네트워크인지 확인하세요.
- PID/로그: `.run/server-8080.json`, `.run/server-8080.log`
- 이미 실행 중인 서버의 재시작 요청은 중복 프로세스를 만들지 않습니다. 사용 중인 포트는 오류로 보고하고 기존 프로세스는 건드리지 않습니다.
- `status` 종료 코드: 실행 중 `0`, 중지됨 `3`, 비정상 `1`. `stop`은 이미 중지된 경우에도 성공합니다.
- 게임 실행 파일만 HTTP로 제공합니다. 소스 참고 자료·로그·디렉터리 목록은 제공하지 않습니다.

## 조작

| 동작 | 1P — BUB | 2P — BOB |
|---|---|---|
| 좌우 이동 | ← / → | A / D |
| 점프 | Space 또는 ↑ | W |
| 발판 아래로 내려가기 | ↓ | S |
| 버블 발사 | Z | F |
| 가까운 버블 터뜨리기 | X | G |

- Enter: 시작 / 계속하기
- P 또는 Esc: 일시정지 / 계속하기
- R: 현재 라운드에서 점수·생명을 초기화하고 다시 시작
- 우측 인원 선택: 새 1인 / 2인 게임 준비
- 라운드 선택: 1~100라운드 연습 시작 (점수·생명 초기화)
- 음향 버튼: 배경음악과 효과음 켜기 / 끄기. 기본은 꺼짐. 게임을 시작하고 우측 상단 스피커 버튼을 누르면 음악이 나옵니다.
- 다른 창으로 전환하면 자동으로 일시정지됩니다.

적에게 버블을 맞히고, 갇힌 적과 몸으로 닿거나 가까이서 터뜨리세요. 오래 방치하면 탈출합니다. 연속으로 터뜨리면 콤보 점수가 올라가고, 과일을 먹으면 500점을 얻습니다. 100라운드의 보스는 번개 버블 100발로 쓰러뜨립니다. 최고 점수는 브라우저에 저장됩니다 (저장 권한이 없으면 현재 실행 중에만 유지).

## 모바일 플레이

휴대폰에서는 게임과 터치 버튼이 한 화면에 표시됩니다.

- 세로 화면: 경기장 바로 아래 왼쪽에 이동·내려가기, 오른쪽에 점프·버블·팡! 버튼이 표시됩니다.
- 가로 화면: 경기장 양옆에 버튼을 배치합니다. 버튼이 경기장을 가리지 않습니다.
- 이동하면서 점프하거나 버블을 발사하는 동시 터치를 지원합니다. 버블 버튼은 길게 눌러 연속 발사할 수 있습니다.
- 위쪽 **설정**에서 플레이 인원과 라운드를 고릅니다. 설정을 열면 자동으로 일시정지됩니다.
- 터치 조작은 1P용입니다. 2P는 기존 키보드 조작을 사용합니다.
- 전체화면에서도 터치 버튼이 유지됩니다. 브라우저가 전체화면을 지원하지 않아도 기본 모바일 화면으로 플레이할 수 있습니다.

## 구현 범위와 참고 자료

- 100개 라운드의 발판 구조는 [Arcade Quartermaster의 Stages & Bosses](https://www.arcadequartermaster.com/bubbob_bosses.html) 스크린샷에서 반복되는 타일 패턴을 추출했습니다.
- [StrategyWiki의 원작 플레이 설명](https://strategywiki.org/wiki/Bubble_Bobble/Gameplay)을 참고했습니다.
- 원작의 스프라이트, 음원, ROM은 실행 파일에 포함하지 않습니다. 그래픽과 효과음은 코드로 생성합니다.
- 원작과 같은 완전한 에뮬레이션은 아닙니다. 적의 수·위치·AI, 물리, 점수 규칙, 보스 이동은 재해석했습니다. 발판은 아래에서 통과할 수 있고 모든 라운드에 안전 바닥을 보완했습니다. 원작의 비밀방, 특수 아이템 전체, 버블 타기, Super Mode와 원작 엔딩은 구현 범위에 포함하지 않습니다.
- `reference/`는 개발 시 확인한 참고 스크린샷으로 실행에 불필요하며 배포 ZIP에도 포함되지 않습니다.
- Original Bubble Bobble © TAITO, 1986. 비공식 팬 프로젝트입니다.

## 파일

- `server.sh` / `scripts/server.py`: 포트별 백그라운드 서버 시작·종료·상태 관리
- `index.html`: 게임 화면, 메뉴, 안내
- `style.css`: 반응형 화면과 디자인 토큰
- `game.js`: 게임 루프, 물리, 렌더링, 입력, 음향
- `music.js`: 원작의 경쾌한 분위기를 참고한 새 칩튠 배경음악 (원곡 음원·멜로디 복제 아님), 16마디 루프와 재생 상태 관리
- `stages.js`: 100개 라운드의 발판 데이터
- `DESIGN.md`: 디자인 및 구현 기준
- `scripts/extract_stages.py`: 참고 이미지에서 발판 데이터 재생성 (`uv run --with pillow python scripts/extract_stages.py`)
- `scripts/browser-qa.mjs`: 개발 환경의 Omowright를 사용하는 브라우저 회귀 검증 (로컬 설치 경로 필요)
- `evidence/qa-results.json`: 실제 브라우저 조작과 격리된 게임 시뮬레이션 결과

## 검증 범위

실제 Chromium에서 시작, 키보드 조작, 일시정지, 2인 플레이, 라운드 선택, 보스 진입, 재시작 및 모바일 너비를 검사했습니다. 격리된 시뮬레이션으로 포획, 점수, 적 탈출, 라운드 전환, 게임 오버와 보스 승리 전환을 검사했습니다. 100라운드 전체를 사람이 끝까지 클리어하는 밸런스 검증이나 Lighthouse 점수 측정은 수행하지 않았습니다.
